# 🌿 NIZHALI

## Smart Sanitary Pad Access and Sustainable Waste Management System

## 📌 Overview

**Nizhali** is a technology-driven solution designed to improve access to sanitary pads while promoting sustainable plastic waste management and women empowerment.

This project includes two major software contributions:

1. **Interactive System Simulation**
2. **Mobile Application Emulator**

These prototypes demonstrate both the complete working of the Nizhali system and the user's experience while accessing Nizhali services.

---

# 🖥️ Interactive System Simulation

The interactive simulation demonstrates the complete workflow of the Nizhali system.

## 🔄 System Workflow

```text
User deposits a plastic bottle
        ↓
Camera captures the material
        ↓
AI/YOLO-based detection
        ↓
Material is identified and validated
        ↓
Bottle is accepted
        ↓
System processes the transaction
        ↓
Sanitary pad is dispensed
        ↓
Voice confirmation is provided
